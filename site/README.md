# Сайт курса

Исходники статического учебного сайта. Контракт контента: [content-contract.json](content-contract.json). Архитектура и решения: [docs/site-architecture.md](../docs/site-architecture.md).

Статус: W00 завершён как проект; реализация (сборщик, интерфейс, тесты, workflow) выполняется в W01 на реальном модуле M00. До этого каталога `dist/` и опубликованного адреса нет.

Планируемые команды (появятся в W01): `npm ci`, `npm run build`, `npm test`, `npm run serve`.

Правила: не редактировать `dist/` вручную; не копировать тексты уроков в компоненты; не добавлять внешние скрипты, аналитику, аккаунты и ключи; публиковать только содержимое allowlist.
