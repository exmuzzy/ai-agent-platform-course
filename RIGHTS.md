# Права на материалы

Оригинальные учебные тексты, задания и вспомогательные скрипты размещены публично для чтения и прохождения курса. Отдельная лицензия на их переиспользование пока не выбрана владельцем репозитория; отсутствие лицензии нельзя трактовать как public domain.

Внешние публикации остаются материалами своих правообладателей. Ссылка на открытый сайт не разрешает копировать весь курс, переводить его целиком для публикации или переносить примеры кода без проверки лицензии.

При подготовке материалов нужно писать самостоятельные объяснения и давать ссылки на первоисточники. Для любого заимствованного кода сначала фиксируются лицензия, версия, атрибуция и выполненные условия; при неясности используется только ссылка.
