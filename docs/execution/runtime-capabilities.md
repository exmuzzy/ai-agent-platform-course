# Возможности среды исполнения (F00)

Дата проверки: 2026-11-08 (UTC+3). Статус: `portable` режим, чистая сводка без приватных данных.

## Режим

**Portable.** Нативного workflow-движка курса нет и не заявляется. Координатор запускает обычных субагентов через инструмент среды, состояние хранит в `workflow/backlog.json` и приватном `.local/checkpoint.json`. Фактический запуск многозадачности подтверждён только записями в разделе «Журнал запусков» ниже.

## Проверенные capabilities

| Возможность | Статус | Как проверено / ограничение |
|---|---|---|
| Независимые субагенты | available | Инструмент создания агента с `task_name`, моделью и reasoning-effort; агент не видит чат координатора |
| Выбор модели на субагента | available | Параметр `model` принимает фиксированный список ID (см. `model-selection.md`); раскрытие фактического resolved ID в ответе не гарантируется |
| Параллелизм | available, лимит политики 4 | Лимит среды не выяснен; применяется политика курса: 4 workers + координатор |
| Отмена / hard stop | partial | Есть прерывание хода агента; принуждение по wall-clock выполняет координатор (опрос + interrupt). Лимиты токенов и числа вызовов средой не принуждаются, это мягкие инструкции |
| Usage / токены | unknown | Среда не возвращает токены по субагентам; расход фиксируется как число запусков и elapsed time |
| Worktree | available | `git worktree` в общем sandbox-репозитории; ветки `course/<task-id>` |
| Файловые результаты | available | Субагенты пишут в общий workspace; границы задаются allowlist и проверяются `git diff` |
| Восстановление сессии | partial | Состояние в git + `.local/checkpoint.json`; sandbox может быть пересоздан, поэтому ключевые состояния коммитятся в репозиторий |
| Web search/fetch | available | Поиск и чтение URL доступны координатору и, по умолчанию, субагентам |
| Терминал / сборка | available | bash в sandbox, Python 3, git; Node.js проверяется в W00 |
| Браузер для QA | available | Управляемый браузер sandbox; также существует локальный браузер пользователя (не использовать без решения) |
| Публикация | available, требует проверки | `gh` авторизован, push-доступ к репозиторию есть; GitHub Pages ещё не включён (`has_pages=false`); также есть `deploy_website` для preview |
| Локальные устройства владельца | available, неоднозначно | Зарегистрировано несколько устройств, включая два Mac; выбор устройства с настоящим harness не сделан и не угадывается |

## Бюджет

- `authoring_budget`: общий лимит runtime не задан владельцем. Действует режим bootstrap из `model-routing.md`: до 4 bounded worker-запусков (включая review и repairs), 600 с на запуск.
- `lab_live_budget`: выключен.
- Единица учёта: число worker-запусков и elapsed time; токены `unknown`.
