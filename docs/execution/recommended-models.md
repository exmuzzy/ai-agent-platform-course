# Модели для запуска создания курса и сайта

Рекомендация на 8 ноября 2026 года: Claude Sonnet 5.5 как координатор, DeepSeek Flash как первый кандидат для небольших исполнительских заданий, отдельный Sonnet или другой принятый профиль для независимого ревью. Это рекомендуемое распределение ролей для данного проекта, а не результат собственного сравнительного benchmark или гарантия завершения за определённую стоимость.

## Если нужно выбрать одну модель

Выберите **Claude Sonnet 5.5** в агентном клиенте, если он доступен. Я рекомендую его для смешанного задания с исследованием, Git, разработкой сайта и контролем качества; Anthropic описывает модель как предназначенную для coding, agentic tool use и enterprise workloads ([описание модели](https://platform.claude.com/docs/en/models/sonnet-5-5/overview)).

Оставьте штатный adaptive-режим, если он доступен; не включайте максимальное усилие для каждого механического преобразования. Координатору нужны реальные tools и возможность продолжать задачи, а не только длинное текстовое окно; в F00 проверяются фактические возможности среды.

## Предпочтительная многоагентная схема

| Работа | Первый кандидат | Как принимать результат |
|---|---|---|
| Координация, DAG, интеграция | Claude Sonnet 5.5 | Согласованные контракты, bounded packets, evidence и продолжение готовых веток |
| Источники, объяснения, quiz | DeepSeek Flash, если доступен | Прочитанные первоисточники, хороший русский, проверяемый учебный результат |
| Небольшой код сайта/практикума | Принятый Flash-профиль; Sonnet для сложного scope | Выполненные тесты, минимальный diff, реальное поведение, не самопохвала |
| Безопасность и сложные решения | Claude Sonnet 5.5 | Независимое ревью, альтернативы, отрицательный тест и откат |
| Review и визуальная/browser QA | Независимый Sonnet либо другой принятый reviewer | Новый контекст, реальное прохождение, просмотр интерфейса и проверка источников |

Это назначения по умолчанию для калибровки, не утверждение превосходства конкретной модели. Если Flash отсутствует в каталоге среды, разрешённый DeepSeek V4 Pro можно проверить на текстовых/кодовых заданиях; API-каталог DeepSeek не доказывает наличие этой модели в Computer или другом агентном клиенте.

По текущей документации DeepSeek alias `deepseek-flash` обслуживается моделью DeepSeek-V4.1-Flash-1017, а `deepseek-v4-pro` соответствует V4-Pro-0813; Flash поддерживает изображения, Pro в этой таблице не поддерживает их ([DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing)). Поэтому не назначать текстовую модель единственным визуальным проверяющим лишь потому, что она умеет анализировать HTML.

Публичные API IDs у провайдера и идентификаторы агентной среды могут различаться. F00 обязан установить actual model ID и инструменты, не передавать наугад название из этой памятки и не менять рабочую маршрутизацию harness автоматически.

## Стоимость и границы рекомендации

На дату проверки прямые API-тарифы DeepSeek Flash ниже опубликованных тарифов Sonnet 5.5; это сравнение прайс-листов, не стоимости принятого результата и не кредитов агентной платформы ([DeepSeek](https://api-docs.deepseek.com/quick_start/pricing), [Anthropic](https://platform.claude.com/docs/en/models/sonnet-5-5/overview)). Повторы, инструменты, проверка и ошибки также расходуют ресурсы, поэтому выбор уточняется на первых полезных заданиях.

Не обещайте стоимость проекта, расход кредитов или завершение в неизвестном лимите. Используйте уже разрешённый бюджет и обеспеченный hard stop; публичное наличие модели не разрешает подключать новый платный API.

Opus или другой усиленный профиль оставьте для точечного сложного блокера после отдельного разрешения. Не запускайте всех авторов на нём по умолчанию; если среда поддерживает только одну модель, независимые контексты и реальное ревью всё равно обязательны, а режим честно называется single-model.
