# Проверка задания на создание курса, версия 0.2

Дата: 8 ноября 2026 года. Проверялись промпт, план, шаблоны, модель ролей, граф заданий и ограничения публикации; исследование индустрии и создание самого курса в эту проверку не входили.

## Объём и результат

- **Независимое ревью:** accept после исправления пяти замечаний к исполнению и повторного чтения затронутых контрактов.
- **Охват:** обязательные U01–U12, сравнение подходов, безопасность и инфраструктура каждого case/lab, четыре разных практических паттерна.
- **Персонализация:** обобщённые профессиональные интересы и диагностика настоящего harness без публикации личной памяти.
- **Публичный diff:** просмотрены изменения и новые документы; собственный harness, закрытый код и реальные корпоративные данные в обновление не включались.

## Исправленные противоречия

- **Планировщик:** исключён повторный dispatch завершённых/работающих заданий, введены однократная декомпозиция, ожидание активной работы и выход без бессмысленного цикла.
- **Финальная версия:** экспорт harness или отдельно разрешённая fixture edition входит до Q01; Q02/Q03 проверяют конкретный кандидат в релиз.
- **Недоступный harness:** F01 может завершить отчёт недоступности, не выдавая его за аудит; явно разрешённая альтернативная ветка не объявляет настоящий экспорт выполненным.
- **Общие файлы:** backlog, source registry и merge принадлежат оркестратору; integrator-worker возвращает delta и меняет только арендованные пути.
- **Лимиты:** packet содержит резерв и реально обеспечиваемую остановку; бюджет, bootstrap и repair counters сохраняются между сессиями.

## Выполненные механические проверки

```text
python3 scripts/check_repo.py
PASS: структура, DAG, registry, локальные пути, ownership U01–U12,
      ограниченный поиск чувствительных паттернов.

python3 -m unittest discover -s tests -v
15 tests: OK.

git diff --check
PASS.
```

Отдельные gitleaks/detect-secrets в среде проверки не обнаружены; утверждение об их успешном запуске не делается. Проверка приватности включала ручное чтение diff и новых материалов, а не только ограниченный паттерн-сканер.

## Границы заключения

Это приёмка задания будущему исполнителю, не приёмка курса версии 1.0. Все учебные authoring tasks остаются `planned`; новые уроки, case studies и лабораторные этим обновлением не создавались.

Не проверялись актуальные внешние источники, цены/качество моделей, работа конкретного orchestration runtime, живые LLM-эксперименты и состояние личного harness. Будущий исполнитель обязан выполнить discovery, исследование и экспериментальные проверки, предусмотренные заданием.
