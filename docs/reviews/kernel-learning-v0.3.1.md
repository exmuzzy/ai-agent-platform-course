# Проверка блока изучения и развития ядра

Дата: 8 ноября 2026 года. Итог независимого read-only review: `accept` для дополнения плана, промпта и контрактов; это не приёмка готовых учебных материалов, работающего корпоративного доступа или новой версии ядра.

## Проверенный scope

- **Содержание:** контракт изучения возможностей ядра, шаблон предложения, USER/BUILDER/ENGINEER, curriculum и M02/M09.
- **Исполнение:** K00 после F01/F02 перед F03, интеграция в план/промпт, ownership общих файлов и обновление выводов в Q01 до финальной QA.
- **Границы:** исходники не навязаны USER, предложения не запускают автоматический рефакторинг, начальные KP-01–06 обозначены гипотезами.
- **Недоступный checkout:** ограниченный исторический отчёт не закрывает F04; отдельно согласованная fixture edition остаётся достижимой.

## Исправленное замечание

Первый вариант нового regression-теста требовал достижимости F04 при любом издании и ошибочно блокировал допустимую замену на F04-FIXTURE. Исправленный тест требует K00 и ровно один прямой release gate; для fixture проверяет зависимости F01/P00, отсутствие зависимости/parent F04, статус blocked у настоящего экспорта и наличие ссылки на evidence.

Добавлены положительный fixture-сценарий и отрицательные случаи без release gate, без evidence, с ложным done F04 и с неправильным parent. Используется только копия данных в памяти; настоящий backlog не переключён на fixture, согласие владельца этими тестами не создаётся.

Наличие ссылки на evidence не доказывает подлинность разрешения: это остаётся предметом содержательной проверки. После исправления независимый reviewer снял blocker и принял весь проверенный scope.
