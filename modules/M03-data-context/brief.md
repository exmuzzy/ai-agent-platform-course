# M03: Данные, контекст и инструменты

Научить управлять происхождением, актуальностью и правами доступа к контексту. Граф знаний является одним из вариантов, а не обязательной инфраструктурой.

- **Уроки:** data lifecycle; retrieval, memory и tool schemas.
- **Fixture:** вымышленные тарифные требования, политика и устаревшая версия документа.
- **Выход:** data/context contract и набор запросов с ожидаемыми разрешёнными источниками.
- **Lab:** stale/conflicting data, запрещённый документ и потеря источника.
- **Проверка:** ограничения доступа действуют и при retrieval, и при повторном использовании памяти.
- **Источники:** SRC-04, SRC-05, SRC-12; точные protocol/API sources уточнить.

Исполнитель: A03. Не публиковать настоящие требования транспортных организаций.
