# Карточки модулей

Здесь пока лежат задания для авторов, а не готовые уроки. Основной маршрут и результаты описаны в [учебной программе](../docs/curriculum.md); машинный реестр модулей находится в [manifest](manifest.json).

Библиотека обслуживает [USER, BUILDER и ENGINEER](../docs/learning-paths.md), а не требует одинакового технического уровня от всех сотрудников. Инженерные требования briefs описывают углубление; автор обязан добавить предусмотренные картой пользовательские и прикладные секции.
