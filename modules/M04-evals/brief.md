# M04: Evals и выбор конфигураций

Научить связывать оценку с outcome и использовать менее дорогую модель без скрытой потери качества. Оценщик тоже нуждается в проверке.

- **Уроки:** error analysis и datasets; сравнение конфигураций и калибровка judge.
- **Выход:** dev set, отдельный holdout, rubric и evidence report.
- **Lab:** сравнить две конфигурации на одинаковых данных, отдельно посчитать failures и стоимость.
- **Проверка:** task success не подменён tool success; mock не выдан за live.
- **Объём:** учебные минимумы и ограничения статистической силы заданы в curriculum.
- **Источники:** SRC-07, SRC-03, SRC-06.

Исполнитель: A04. Live API по умолчанию выключены; отсутствие бюджета не разрешает выдумывать измерения.
