# M00: Доступ, первая задача и диагностика

Создать эталонный модуль сначала для обычного сотрудника, затем отдельное инженерное приложение. Доступ, безопасные данные и первая проверенная задача важнее устройства ядра; выдуманный onboarding недопустим.

- **Вход USER:** проверенный учебный интерфейс и роль либо явно обозначенная offline-симуляция; без Git/Python и личных ключей.
- **Выход USER:** первая задача, сверка результата, обнаруженная ошибка, отклонённое действие и знание поддержки.
- **Уроки:** доступ и правила данных; использование, проверка, остановка и помощь.
- **Lab:** синтетическое обращение → структурированный результат → проверка человеком; есть нормальный и запрещённый сценарии.
- **Приложение ENGINEER:** checkout/fixture, версии, source/runtime/instructions, capability matrix и отрицательный тест.
- **Проверка:** USER проходит без инженерных подсказок; ENGINEER различает код, unit-test и end-to-end evidence.
- **Источники:** SRC-02, SRC-07 из общего реестра.

Исполнитель: P00, приёмка Q00. Пока этот модуль не принят, массовое авторство не запускать.
