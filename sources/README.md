## Следующий исследовательский шаг

Найти конкретные официальные sections по выбранному runtime: checkpoints/recovery, tool authorization, retrieval ACL, evaluation и instrumentation. Затем подобрать профильный источник по platform-as-product/change management; не закрывать весь M08 одним вводным курсом Google.

В каждом модуле обязательное чтение ограничивается двумя-тремя точными разделами. Остальные материалы помещаются в необязательное углубление, чтобы курс не стал каталогом ссылок вместо обучения.
