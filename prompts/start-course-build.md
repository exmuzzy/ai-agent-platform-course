# Стартовый промпт оркестратору

Скопируй блок ниже в выбранную агентную среду. Он не требует конкретной модели или выдуманного workflow API и должен исполняться поверх её действующих правил.

```text
Создай учебный курс по плану публичного репозитория:
https://github.com/exmuzzy/ai-agent-platform-course

Цель: перейти от моего существующего harness к управляемой агентной
платформе компании. Не создавай новый harness с нуля. Я разрешаю менять
и публиковать мой harness в рамках курса, но не секреты, персональные
данные, чужие закрытые материалы или production-конфигурацию с доступами.

Работай на русском, недорогой моделью, через bounded multi-agent dynamic
workflow. Сам являйся оркестратором, раздавай небольшие packets независимым
субагентам. Не передавай каждому весь курс, harness или историю диалогов.

Сначала:
1. Прочитай AGENTS.md, docs/course-build-plan.md,
   docs/execution/dynamic-workflow.md и workflow/backlog.json.
2. Выполни F00: определи реальные возможности runtime по установленной
   справке. Не выдумывай команды /dwf, DSL, SDK или API.
3. Продолжи F01/F02 параллельно: baseline harness и проверка источников.
4. Для изменения harness используй отдельный worktree/ветку, baseline,
   positive/negative/regression tests, независимое review и rollback.
5. Выполни F04: очищенный учебный профиль настоящего harness в labs/harness/.
   Не переносить исходную Git-историю, память, рабочие данные и секреты.
   Если checkout недоступен, блокируй только F04/связанные задачи;
   остальную часть курса создавай на synthetic fixture.
6. Сделай F03, эталонный M00 (P00) и независимое Q00.
7. Только после принятия эталона раскрой A01–A09 на маленькие child tasks,
   максимум 4 workers одновременно, без вложенного fan-out.
8. Автор не принимает собственную работу. После максимум 2 repair rounds
   блокируй повторяющуюся проблему и продолжай независимые задачи.
9. Сохраняй checkpoint после каждого принятого или blocked задания.
   Не повторяй уже выполненную работу после возобновления.

Обязательный результат:
- 10 модулей M00–M09 по curriculum; в каждом 2 урока, lab, assessment,
  solutions, evidence и навигация.
- Русские авторские объяснения, проверенные первоисточники, контрпримеры.
- Синтетический транспортный кейс и обязательный offline/mock path.
- Измеримые артефакты: стратегия, архитектура, evals, безопасность,
  эксплуатация, экономика, operating model и итоговая защита.
- Очищенный и воспроизводимый учебный профиль harness, если доступен код.
- Clean-checkout dry-run, независимое content/privacy review и CI.

Необязательны live API и облачные сервисы. Не расходуй на них деньги
без явного разрешения и лимита. Не повышай класс модели автоматически.
Мок не доказывает качество LLM; no-run не является passed.

Разрешена работа и публикация учебных материалов этого репозитория и
очищенного собственного harness. Не выполнять production-rollout,
изменение глобальных настроек, force-push и удаление репозиториев.
Если среда требует approval на push/merge, соблюдай его.

Начни с F00, а не с нового общего плана. Выполняй готовые безопасные задачи
до достижения лимита запуска, затем оставь короткий handoff:
сделано / доказательства / не проверено / блокеры / следующие task ids.
```

## Что ожидать от первой сессии

Сессия должна дать проверенный режим оркестрации, профиль учащегося/стенда, актуализированные sources и план конкретного эталонного модуля. Если контекст или usage закончились раньше, корректный результат: checkpoint и точное продолжение, а не заявление о готовности курса.
